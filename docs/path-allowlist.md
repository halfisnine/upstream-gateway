# 渠道接口透传白名单

2026-11-18。配置格式升级到 schema 6；没有数据库表结构变更。

## 使用方式

渠道列表 → 编辑渠道 → 展开「接口透传白名单」。每项填写请求方法、完整路径、使用的协议设置，保存到草稿后点击顶部待发布角标统一发布。白名单随完整配置版本保存，各节点按原轮询周期热更新；历史查看、比较和恢复包含白名单。

New API 的「从上游获取」通常请求 `GET /v1/models`。在对应渠道点击「添加模型列表接口」，选择正确的协议设置后发布即可。New API 的 Base URL 仍填 `http://upstream-gateway:8080/r/apistar`，不增加 `/v1`；Key 继续在 New API 中填写。

```json
"path_allowlist": [
  {"method": "GET", "path": "/v1/models", "protocol": "openai_chat"}
]
```

`GET /r/apistar/v1/models?limit=20` 命中上述条目，转发到该渠道 OpenAI Chat 的有效上游地址加 `/v1/models?limit=20`。协议覆盖地址优先于渠道默认地址，地址原有路径前缀保留。多种协议即使共用 `/v1/models`，也由这条配置明确选择目标和认证方式，不根据模型名称猜测。

快捷按钮优先选择已启用的 Chat、Responses、Messages、Gemini；Gemini 快捷路径为 `/v1beta/models`。实际供应商或 New API 渠道适配器可能使用不同路径，需按实际请求填写。这不等于已经验收所有供应商的模型发现 API。

## 匹配与响应契约

- 每渠道最多 64 项，按 HTTP 方法和路径大小写精确匹配，方法支持 GET、HEAD、POST、PUT、PATCH、DELETE、OPTIONS。相同方法加路径不允许重复；引用的协议必须已启用。
- 路径以 `/` 开头，不含 `/r/渠道标识`、查询串、通配符或正则表达式。拒绝编码字符、点段、重复斜线、反斜线、控制字符和完整 URL。`/v1/models` 不包含 `/v1/models/` 或子路径，HEAD 需单独配置。
- 查询串不参与路径匹配，语法有效时保留原始查询串，包括分页参数和重复参数。认证仍从所选协议要求的唯一认证头读取；不新增从 query 读取 Key 的能力。上游地址只能取自已发布配置。
- 白名单优先于内建协议路由；显式把现有生成接口加入白名单，也会让该方法和路径绕过错误处理。未命中的请求继续执行既有协议转发、查询限制和错误处理规则。
- 命中后完整保留上游最终 HTTP 状态、正文原始字节及端到端响应头，不解析 JSON/SSE、不改写成功或错误正文、不做正文错误检查、不匹配错误规则、不生成拦截日志。压缩、普通文本、JSON、SSE、分页响应、余额错误均遵循相同规则。
- 3xx 状态与 Location 交给调用方，网关不跟随重定向。支持 HEAD、204、304 和响应 trailer 的 HTTP 语义；不提供 WebSocket/HTTP Upgrade 或 CONNECT 隧道。逐跳头按 HTTP 代理规则移除，连接分帧不是逐字节复制对象。
- 入站凭证检查、已配置的认证头转换、请求正文 16 MiB 上限、并发准入、超时和取消仍有效。浏览器 Cookie、Origin、Referer、转发链及非选中认证头不发送给上游；其他端到端请求头可透传。响应使用 32 KiB 缓冲复制并及时刷新，不把整份错误正文读入内存。
- 连接失败、超时或准入拒绝没有可透传的上游响应，仍返回网关自身的安全错误。响应已开始后的流中断直接结束，不拼接 JSON 或伪造结束标记。不增加自动重试、续写或上游回退。

删除或修改条目只影响节点应用新快照之后的新请求；已开始的响应继续使用原快照和连接。白名单请求与模型请求共享节点及上游并发限额，发布不能重置在途计数。

## 升级与回退

先把所有网关节点更新到支持 schema 6 的镜像，再发布新配置。新程序可以读取旧 schema 3/4/5；schema 5 的并发、正文检查、错误规则保持不变，白名单默认为空，升级镜像不会自动放行接口。schema 3/4 继续使用原有兼容转换。已发布历史快照不修改。

旧程序无法读取 schema 6。发布 schema 6 后不能直接降级旧程序；需要专门评估配置兼容性，不通过恢复数据库覆盖新发布数据。此项是配置格式升级，不是数据库迁移，也不需要重建数据库或更换密钥。

## 验证

Go 回归覆盖严格配置、旧快照兼容、成功/失败/重定向/压缩正文透传、不记拦截日志、协议覆盖与认证头、路径及方法匹配、并发共享和热更新中已有流继续完成。临时 PostgreSQL 双节点浏览器验收覆盖添加/校验/发布/删除白名单、两个节点获取模型列表和错误原文透传；测试只访问本地模拟上游。
