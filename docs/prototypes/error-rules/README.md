# 错误规则与拦截日志静态预览

本目录是独立设计原型，不进入 Go 控制台构建，不连接真实网关、数据库或上游。无外部依赖、网络字体或 CDN；数据与草稿只保留在当前页面内存中，刷新恢复示例。

直接打开 `index.html`，或在仓库根目录启动仅监听回环的独立预览：

```sh
python3 -m http.server 19094 --bind 127.0.0.1 --directory docs/prototypes/error-rules
```

访问 http://localhost:19094 。若浏览器与工作区不在同一台机器，需使用开发工具的端口转发。

可演示：

- 规则列表、筛选、组内顺序、启停、从预设新增、编辑与删除。
- 指定渠道优先于公共规则；多种错误来源、上游状态范围、代码 / 关键词备选条件组、返回状态及固定文案。
- 当前表单的本地试匹配，包括余额不足、SSE 中途错误、正常回答提到余额不足。
- 草稿发布预览和模拟节点同步；日志仍显示事件发生时的版本。
- 日志时间 / 渠道 / 状态 / 节点 / 请求编号筛选、详情与记录策略。
- 日志队列已满、明细丢失的示例提示。

原型范围：协议筛选暂展示单选；内容条件展示两个常用备选组，并非完整条件构建器。试匹配处理手工输入的已提取字段，不解析真实 JSON / SSE，不代表已实现规则引擎。日志仅有 8 条虚构记录，不展示多页游标。资源策略只读展示建议值。正式实现前以设计评审结论为准。

规则与日志设计见 ../../error-rules-proposal.md 。
